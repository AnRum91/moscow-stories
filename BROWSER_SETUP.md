# Как проверить проект без Node.js на своём компьютере

Важно: я не смог запустить сборку (в моей среде нет интернета), поэтому ни один из способов ниже мной **не проверялся**. Если шаг не сработает — пришлите текст ошибки или скриншот.

## Почему не открывается на телефоне
Проект — исходный код (React + TypeScript). Его нужно один раз собрать командами Node.js, и только потом открывается страница. Файлы из архива сами по себе в браузере не запустятся. StackBlitz, насколько мне известно, запускает Node.js прямо в браузере и рассчитан на настольные браузеры, поэтому на телефоне может не работать.

## Способ 1 (рекомендуется): GitHub собирает и публикует сам
Нужны бесплатный аккаунт GitHub и доступ к любому настольному браузеру хотя бы один раз (с телефона загрузка папки неудобна).
1. На github.com создайте новый репозиторий (Public).
2. Распакуйте `moscow-stories.zip`. В репозитории нажмите **Add file → Upload files** и перетащите **содержимое папки `moscow`** (файлы `package.json`, `index.html`, папки `src`, `public` и т. д.). Нажмите **Commit changes**.
3. Папка `.github` может не попасть в загрузку (скрытая папка). Создайте файл вручную: **Add file → Create new file**, в имени введите `.github/workflows/ci.yml` и вставьте содержимое файла `ci.yml` из архива. Нажмите **Commit**.
4. Откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Откройте вкладку **Actions**. Запустится задача «CI»: она выполнит `npm install`, `npm test`, `npm run build` и опубликует сайт.
   - Зелёная галочка: откройте ссылку из шага «deploy» (или Settings → Pages). Ссылка работает на телефоне по HTTPS: можно проверять карту, геолокацию, установку на главный экран и офлайн.
   - Красный крестик: откройте упавший шаг, скопируйте текст ошибки и пришлите мне — я исправлю код.

## Способ 2: StackBlitz на настольном компьютере
Любой компьютер с Chrome или Edge (подойдёт чужой или библиотечный). На stackblitz.com импортируйте репозиторий из способа 1: адрес вида `https://stackblitz.com/github/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ`. Затем в терминале StackBlitz: `npm install`, `npm run dev`.

## Способ 3: GitHub Codespaces
В репозитории: **Code → Codespaces → Create codespace**. В терминале: `npm install && npm test && npm run build && npm run dev -- --host`. Работает в браузере, но на телефоне неудобно.

## Что нужно прислать мне после запуска
- Результат шага `npm test` (сколько тестов прошло и какие упали).
- Результат шага `npm run build` (успех или текст ошибки).
- Ссылку или скриншоты, что видно на телефоне. Особенно: карта, выбор маршрута, скачивание, поведение без интернета, геолокация, голосовой гид.

Пока эти шаги не выполнены, сборка, тесты и работа в браузере считаются **не подтверждёнными**.
